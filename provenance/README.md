**In one paragraph.** Taking a mechanism from someone else's work is an engineering decision with three obligations: say where it came from, say what was deliberately *not* taken, and say what the mechanism may never decide. This register carries all three for every mechanism, so that "AETHRION adapted this" is a checkable statement rather than a claim in prose. **No entry has reached `ADAPTING` yet** — every row below is a decision on paper, and `pinned_commit` stays `null` until code actually moves, at which point `check_upstream_lineage.py` starts requiring it.

> **Upstream identity is engineering lineage, not product architecture.** None of the systems below appears as a runtime module, a directory or a backend. What is taken is a mechanism; where it came from is recorded here and in `NOTICE`, and nowhere else.

---

## Assimilation types

| Type | Meaning |
|---|---|
| **DIRECT_ADAPT** | Source code is taken and refactored into AETHRION contracts. Requires a permissive licence, a pinned commit, a named file list, a characterisation suite and a NOTICE entry. |
| **ADAPTIVE_REIMPLEMENT** | The mechanism is specified from the paper and/or implementation, then written natively. No source is copied, so no licence obligation arises; the lineage is recorded anyway. |
| **PATTERN** | An architectural idea implemented here with no code taken. Attribution and honesty about divergence are the obligation. |
| **STANDARD** | A format or model implemented as specified. Conformance testing is the obligation. |
| **BENCHMARK** | Measures the system; is never part of it. A benchmark score is qualification evidence, never gate authority. |
| **DEPENDENCY** | Called at runtime, not copied. Version pinning and failure semantics are the obligation. |
| **DEFER** | Examined, plausible, not taken now. The reason is recorded so it is not re-examined from scratch. |
| **REJECT** | Examined and deliberately not taken. The reason is recorded. |

## What this register is not

It is not a dependency list — nothing here is installed. It is not a reading list — an entry means a decision was taken about a mechanism, including the decision not to take it. And it is not a claim of implementation: `status` is the honest field, and every row currently reads `PROPOSED` or `REJECTED`.
